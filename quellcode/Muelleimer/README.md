# Muelleimer

- `/trash` (auch `/muell`) öffnet einen Mülleimer. Was beim Schließen drin liegt, wird gelöscht.
- `/trash undo` holt alles zurück, was in den letzten 2 Minuten weggeworfen wurde (`undo-seconds`).
- **Mülleimer-Block:** Kessel + Kaktus in der Werkbank (formlos) ergibt einen schimmernden „Mülleimer“.
  Aufstellen, Rechtsklick → Mülleimer öffnet sich. Abbauen gibt wieder den Mülleimer (nicht einen normalen Kessel).
  Er füllt sich nicht mit Regen/Wasser, lässt sich nicht von Kolben schieben und übersteht Explosionen.
  Mit Schleichen + Block in der Hand kann man ganz normal Blöcke daneben setzen.
- `/trash block [Spieler] [Anzahl]` gibt Mülleimer-Blöcke (nur OP/Konsole).

Rechte: `muelleimer.use` (alle), `muelleimer.block` (OP).
Die Positionen der Mülleimer werden im Chunk selbst gespeichert – keine extra Datei.
